The rule of thumb

Set level once — at the preamp. Speech averages −18 to −20 dBFS, peaks near −10, never above −6. Run every later stage at unity. Turn the finished master up to the delivery target. Set the speakers to a calibrated SPL.

“−18 dB at every stage, all the way to the speakers” → only the converter speaks dBFS. Mics speak millivolts (dBV), line gear speaks dBu, delivery speaks LUFS, the room speaks dB SPL.
Alignment: −18 dBFS = 0 dBu (EBU R68) · −20 dBFS = +4 dBu = 0 VU (SMPTE RP155) · plugin habit: 0 VU ≈ −18 dBFS.
